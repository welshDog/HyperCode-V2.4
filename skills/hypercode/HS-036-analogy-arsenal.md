## How To Use Analogies

1. **Lead with the analogy** — real-world thing first, tech name second
2. **One analogy per concept** — don't mix metaphors
3. **Revisit it** — when explaining steps, link back: "remember, this is the tap on the shoulder..."
4. **Invite theirs** — "What does Redis remind you of?"

## Why This Works For ND Brains

- Concrete → Abstract: ADHD + dyslexic brains grip concrete images faster
- Memory hooks: analogies create emotional anchors that outlast dry definitions
- Pattern matching: autistic thinkers love finding the structural similarity
