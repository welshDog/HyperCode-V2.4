# HS-034 — 7-Beat Module Teaching Structure

> **Extracted from:** `CLAUDE.md §8` · HyperCode-V2.4
> **Use for:** Every module, lab, or lesson in the Hyper-Vibe-Coding-Course

---

## The 7 Beats — Every Module Must Have All 7

| Beat | Name | What It Does |
|---|---|---|
| 1 | **STOP** | Plain English context BEFORE any tech |
| 2 | **WHY** | Real-world use case (Netflix, Uber, Stripe refs) |
| 3 | **HOW** | Step-by-step with ⏱️ time estimates |
| 4 | **WIN** | Clear, celebratable moment |
| 5 | **NEXT** | Warm bridge to next module |
| 6 | **HELP** | Troubleshooting that normalises problems |
| 7 | **REWARD** | BROski$ XP claim |

## Philosophy

> **"Build first, learn second. Speed of thought. Dopamine momentum."**

- For ADHD, dyslexic, autistic, and neurodivergent builders
- No previous experience needed
- Quick win first — then explain why it works

## Example Application

```
Module: "Your First Docker Container"
1. STOP — "Docker is a box that holds your app. That's it."
2. WHY — "Spotify runs in containers. So does Netflix."
3. HOW — `docker run hello-world` ⏱️ 2 mins
4. WIN — "You just ran a container! 🎉"
5. NEXT — "Next: your own app in that box."
6. HELP — "Getting 'permission denied'? Try sudo or add yourself to docker group."
7. REWARD — "+50 BROski$ claimed! /daily in Discord"
```
