## 📋 What This Folder Is

- **Not a backlog.** Not a graveyard. A **build queue**.
- Every file = one upgrade idea, fully spec'd with WHY + HOW + build order.
- When it ships, it moves to `WHATS_DONE.md`. It never gets deleted here — it gets marked ✅.
