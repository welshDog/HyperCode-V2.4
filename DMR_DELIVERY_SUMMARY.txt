## ✨ Key Features

### 1. **Resource-Aware Inference**
- Models load on-demand (not always burning RAM)
- Auto-unload after 5 min idle
- Fallback to smaller model on timeout
- Designed for your 8GB RAM ceiling

### 2. **OpenAI-Compatible API**
- Drop-in replacement for `ollama.Client`
- No Agent X code changes (just swap clients)
- Works with existing OpenAI libraries

### 3. **Streaming & Metrics**
- Stream tokens as they arrive
- Track latency, token counts, fallback usage
- FastAPI integration ready

### 4. **Tested & Production-Ready**
- 7 validation tests (connectivity, inference, fallback, concurrency)
- Comprehensive error handling with retry logic
- Structured logging and debugging

## 🔧 Integration Example

Replace this:
```python
from ollama import Client
client = Client(host='http://hypercode-ollama:11434')
response = client.chat("Write a Dockerfile")
```

With this:
```python
from agentx.dmr_client import DMRClient

async with DMRClient() as client:
    response = await client.infer("Write a Dockerfile")
    # Or stream:
    async for chunk in client.infer_stream("..."):
        print(chunk, end="")
```

## 🎯 Why This Levels Up Agent X

| Before (Ollama) | After (DMR) |
|---|---|
| Separate container, always running | Embedded sidecar with auto-unload |
| Fixed in memory (wastes RAM) | Load on-demand, free after 5 min idle |
| No fallback on slow models | Auto-fallback to SmolLM2 360M |
| No metrics/observability | Built-in latency, token, fallback tracking |
| One inference engine (llama.cpp) | Swap engines via config (llama.cpp → vLLM) |
| Hard-coded Ollama host | Flexible via DMR_HOST env var |
| Manual model management | Automatic preload + unload |
